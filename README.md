# المصحف الرقمي برواية قالون

مشروع مفتوح المصدر يهدف إلى إنشاء عارض رقمي لمصحف برواية قالون، مع الحفاظ قدر الإمكان على تخطيط المصحف المطبوع من حيث الصفحات والأسطر وتوزيع الآيات.

## 🎯 هدف المشروع

الهدف الأساسي هو بناء Renderer قادر على عرض المصحف الرقمي بطريقة تحاكي تخطيط النسخة المطبوعة، مع الاعتماد على بيانات منظمة بدل الاعتماد على صور الصفحات.

يشمل ذلك:

- عرض نص القرآن برواية قالون.
- ربط الآيات بالصفحات.
- تحديد بداية ونهاية الآية داخل السطور.
- التعامل مع تخطيط السطور.
- استخدام بيانات الإحداثيات عند الحاجة.
- دعم الخط المستخدم في عرض النص.
- بناء عارض صفحات يمكن تطويره لاحقًا إلى مصحف رقمي كامل.
